01 / Repository evidence

可在儲存庫直接核對的內容

以下每項均對應現有檔案，說明公開資料範圍，但不代表目前檔案已組成可直接編譯的完整產品。

賽事行動介面

9 張截圖顯示報名倒數、線上賽事、訓練賽、資訊、影片、兌換、設定與收藏牌局。

C++ 遊戲通訊

gameserver.cpp/.h 負責外部訊息、協定版本檢查，以及單人、全桌與旁觀者訊息發送。

Tars 服務協作

MySQL 設定讀取

Lua 與資源規範

包含 Lua .bytes、拼音/字典資源，以及 Unity 風格的資源命名與圖集規範。

介面與部署資料

API 文件涵蓋登入、房間、牌桌與賽事訊息；部署指南中的完整依賴仍需驗證。

公開範圍與驗證邊界

目前是原始碼片段、資源、SQL、文件與截圖的集合，缺少完整 CMake/Unity 工程、部分協定標頭與設定，因此不能只憑此儲存庫宣稱可直接建置、上線或通過 iOS 審核。

05 / FAQ

常見問題

這是完整可執行的工程嗎？

目前公開檔案不足以獨立建置，需要補齊相依檔案、協定、建置設定與客戶端工程。

可以證明哪些賽事功能？

截圖可證明賽事列表、報名、倒數、訓練賽、資訊/影片和收藏介面；API 文件另有賽事訊息範例。

服務端使用哪些技術？

可直接核對 C++、Tars 風格代理、MySQL 與訊息介面；Redis、Java 和 Unity 僅見於部署文件，需再驗證。

可以直接商用嗎？

應先解決兩份授權文件的表述差異，並確認品牌、賽事素材與完整工程的授權。

從原始碼證據開始評估

先讀原始碼地圖、API 文件與部署邊界，再決定要補齊的工程檔案和測試範圍。
